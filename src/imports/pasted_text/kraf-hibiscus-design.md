Design a professional web-based business management system for “Kraf Hibiscus Business Management System”.

The system is for Kraf Hibiscus, a community-based handmade craft business that collects recycled fabrics and turns them into handmade products such as scrunchies, bags, purses, and fabric crafts.

Design style:
- Theme color must be cream and soft pink.
- Use a professional, clean, warm, and organized visual style.
- The design should look like a real business website, not a student mockup.
- Use cream background, soft pink buttons, dusty rose accents, dark brown text, white cards, and light beige borders.
- Suggested colors:
  - Background: #FFF8F0
  - Main pink: #EFA3B7
  - Dark pink: #C76B83
  - Text: #3B2F2F
  - Card background: #FFFFFF
  - Border: #E8D8C8
  - Success green: #8FBF9F
  - Warning orange: #E8A87C
  - Error red: #C94C4C
- Use rounded cards, clean spacing, soft shadow, and consistent button styles.
- Use a website layout for customer pages and an admin dashboard layout for internal management pages.
- Use modern fonts similar to Poppins for body text and Playfair Display or elegant serif style for headings.

Create the following customer/public website screens:

1. Homepage / Landing Page
Purpose: Introduce Kraf Hibiscus and guide customers to browse handmade products.
Layout:
- Top navigation bar with logo “Kraf Hibiscus”
- Menu: Home, Products, About, Community Recycling, Contact
- Right side buttons: Login and Shop Now
- Hero section with heading: “Handmade Products from Recycled Fabrics”
- Short description: “Kraf Hibiscus transforms recycled fabrics into handmade items while supporting community-based sustainability activities.”
- Two buttons: “Shop Handmade Products” and “Learn About Recycling”
- Right side hero image placeholder showing handmade scrunchies, fabric bags, purses, and soft floral craft style
- About Kraf Hibiscus section
- Product Category Preview section with four cards:
  Scrunchies, Bags, Purses, Fabric Crafts
- Community Recycling section showing three steps:
  1. Collect old clothes and fabric
  2. Sort and prepare materials
  3. Create handmade products
- Footer with contact information, quick links, and Admin Login link

Button interactions:
- Shop Now and Shop Handmade Products go to Product Catalogue Page
- Login goes to Customer Login Page
- Admin Login in footer goes to Admin Login Page
- Product category cards go to Product Catalogue Page filtered by category

2. Product Catalogue Page
Purpose: Allow customers to browse handmade products.
Layout:
- Same customer navigation bar
- Page title: “Shop Handmade Products”
- Search bar
- Category filter: All, Scrunchies, Bags, Purses, Fabric Crafts
- Price filter
- Product grid with product cards
Each product card should include:
- Product image placeholder
- Product name
- Category
- Price in RM
- Stock availability
- View Details button
- Add to Cart button
- Cart icon on top right

Button interactions:
- View Details goes to Product Details Page
- Add to Cart shows a small success message and updates cart icon
- Cart icon goes to Cart Page

3. Product Details Page
Purpose: Show one product in detail.
Layout:
- Large product image placeholder
- Product name
- Category
- Price
- Product description
- Available stock
- Quantity selector
- Add to Cart button
- Buy Now button
- Back to Products button

Button interactions:
- Add to Cart goes to Cart Page or shows success message
- Buy Now goes to Checkout Page
- Back to Products goes to Product Catalogue Page

4. Cart Page
Purpose: Allow customer to review selected items before checkout.
Layout:
- Cart item list with image, product name, price, quantity selector, remove button
- Order subtotal
- Checkout button
- Continue Shopping button

Button interactions:
- Checkout goes to Checkout Page
- Continue Shopping goes to Product Catalogue Page
- Remove deletes selected cart item

5. Checkout Page
Purpose: Allow customer to confirm order and payment details.
Layout:
- Customer information section
- Delivery or pickup option
- Order summary section
- Payment method selection:
  Online Transfer, E-wallet, Cash on Pickup
- Place Order button
- Back to Cart button

Button interactions:
- Place Order goes to Order Success Page
- Back to Cart goes to Cart Page

6. Order Success Page
Purpose: Show successful order confirmation.
Layout:
- Success icon
- Message: “Your order has been placed successfully.”
- Order ID
- Order summary
- Payment status
- View My Orders button
- Continue Shopping button

Button interactions:
- View My Orders goes to Customer My Orders Page
- Continue Shopping goes to Product Catalogue Page

7. Customer Login Page
Purpose: Customer login.
Layout:
- Email input
- Password input
- Remember me checkbox
- Login button
- Register link
- Forgot Password link
- Use cream and pink theme

Button interactions:
- Login goes to Product Catalogue Page or My Orders Page
- Register goes to Customer Register Page
- Forgot Password goes to Forgot Password Page

8. Customer Register Page
Purpose: Customer account registration.
Layout:
- Full Name input
- Email input
- Phone Number input
- Password input
- Confirm Password input
- Register button
- Back to Login link

Button interactions:
- Register goes to Customer Login Page
- Back to Login goes to Customer Login Page

9. Customer My Orders Page
Purpose: Customer views order history and status.
Layout:
- Table or cards showing:
  Order ID, Order Date, Total Amount, Payment Status, Order Status, Actions
- Actions: View Details, Cancel Order if allowed, Confirm Received if delivered

Button interactions:
- View Details opens Order Details Page
- Cancel Order opens confirmation popup
- Confirm Received updates order status to received

Make all screens visually consistent and suitable for a professional web-based system.
